HTML 5

HTML é a sigla para HyperText Markup Language, ou seja, Linguagem de Marcação de Hipertexto. É uma linguagem de marcação utilizada na construção de páginas na web. O HTML é utilizado para estruturar o conteúdo da página, como textos, imagens, links e outros elementos.
